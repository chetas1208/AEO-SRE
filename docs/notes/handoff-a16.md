# Handoff A16 (execution-architecture refactor: manual executor first, GitHub optional)

Product direction change: GitHub was never the thesis (it leaked in from the BlackBox reference). AEO SRE is a closed-loop
learning system; execution is an interface and the app works fully with ONLY the ManualExecutor.

## What changed
- `app/interventions/executor.py`: `InterventionExecutor` protocol (`execute(intervention, approval, ...) -> ExecutionResult`, `name`, `capability()`), `ExecutorCapability`, `ExecutionStatus.AWAITING_HUMAN_EXECUTION` (DB `executions.status` is a free `String(32)`, no enum migration), `check_gate` (shared approval gate), `normalize_executor_choice`, new `select_executor(action, choice=None, dry_run=None)`:
  default -> `ManualExecutor` for ALL actions; GitHub only if `choice="github"` AND configured (explicit `dry_run=True` preview allowed unconfigured); explicit-but-unavailable is REFUSED (`github_not_configured`), no silent GitHub dry-run fallback. `ManualTaskExecutor` removed. `GitHubPRExecutor` unchanged (name `github_pr`), now has `capability()`.
- `app/interventions/manual.py` (new): `ManualExecutor` (no external mutation; builds the package; `observe` -> `succeeded` immediately), `build_package`, `ProfoundAgentExecutor` (unavailable stub), `executor_capabilities`, `prepare_manual_package` (idempotent), `record_manual_execution(session, intervention_id, executed_by, executed_at=None, reference_url=None, note=None, actual_change=None, *, actor_type="human")`. Errors: `HumanActorRequired` (403), `InvalidExecutionTime` (future, 422), `AlreadyExecuted` (409), `NotExecutable` (409: not approved/wrong state/observe/no experiment).
- Package (stored on `Execution.package`): version, action, kind, title, summary, `target{url,paths}`, `changes[{path,target_url,change_type,patch_mode,section_id,proposed_text,current_content,current_content_known,diff}]`, `diff`, `manual_task`, `steps`, `why`, `evidence_summary`, `risk`, `rollback`, `observation_window{delay_hours,duration_days,note}`, `approved_by`, `modified_by_human`, `policy_version`, `requires_human_step`.
- Models: `Execution` gained `package`, `actual_change` (`{text, recorded_by, recorded_at}`, verbatim), `deviation`, `executed_by`, `executed_at`, `note`; defaults now `executor="manual"`, `dry_run=False`. Initial migration regenerated (`scripts/regen_initial_migration.sh`); the shared dev DB `aeo` needs the 6 new columns (drop/recreate or ALTER).
- `ProposedChange.kind` default is now `page_change` (`github_pr` still accepted as a legacy alias; see `PAGE_KINDS`).
- `services/pipeline.py`: `execute(session, iid, executor=None, dry_run=None)` = activate with the chosen executor. Manual page action: issue package, STOP at `awaiting_human_execution` (incident stays `approved`, experiment `approved`). Observe: executes immediately (real, window starts). GitHub only on explicit choice. New `record_executed(...)` wraps `record_manual_execution`, commits, emits SSE (`state`, `execution.completed`, `verification.waiting`). Worker `execute_intervention` forwards `executor`.
- Human step: incident `approved -> executing -> executed -> awaiting_verification` via the state machine (actor = the human); experiment `begin_execution` + `mark_executed` with the window anchored at `executed_at` (+ `VERIFICATION_DELAY_HOURS`, default 48). `Execution.dry_run=False`, so rewards, verification and `historical_outcome_range` count it (tested). Deviation (`actual_change`) is stored verbatim, flagged on the row, noted in the experiment timeline and audit; the proposal itself is never rewritten.
- API: `POST /api/interventions/{id}/approve|modify` now ACTIVATE the experiment (manual: synchronous package; optional `executor` in the body, validated BEFORE deciding, 409 `github_not_configured`). `POST .../execute` = (re)activate, default manual, idempotent (no second package); `{executor:"github", dry_run?}` queues the old job. New `POST .../executed` (body `executed_at?, reference_url?, note?, actual_change?`, `X-Actor` human; non-human names like `system/pipeline/model` -> 403). `InterventionOut` gained `package`, `manual_execution_pending`; `execution_target` is the target URL/path only; `executor` defaults to `manual`. `ExperimentRow` gained `executor`, `awaiting_human_execution`, `deviation`; display `Awaiting Execution` while the package is pending.
- CTA: `approve` (label "Approve"), after approval `mark_executed` ("Mark as executed"), then "Awaiting Measurement"; allowed action `record_execution`.
- Capabilities: `github` removed from core `capabilities` (so it can never degrade `overall`); new `executors{manual: healthy, github: unavailable (optional), profound_agent: unavailable}`. Settings integrations now: profound, llm, manual, github (optional=true, kind=executor), profound_agent, cms.
- Config: `.env.example` rewritten (required block has no GITHUB_*; commented "optional executors" section); root `.env` GITHUB_* lines commented out (token/owner/repo were empty; BASE_BRANCH had a non-secret value, also commented). `Settings` keeps `github_*` optional.
- Frontend: "Approve & Execute" -> "Approve"; ApprovalDialog says approval activates an experiment and no longer calls execute; new `components/incidents/InterventionPackage.vue` (exact diff/text, steps, target, rollback, evidence, window + "Mark as executed" form with reference URL, note, "I changed something different" -> paste actual change, future time blocked, never optimistic); `useApproveIntervention.recordExecuted`; Experiments table shows Executor; GitHub only appears as "GitHub PR (optional)" / "GitHub dry-run preview"; Settings shows executors without alarm.
- Docs: Plan.md 4.8/golden path/step 9, UI.md 21-24/CTA, README, ARCHITECTURE, THIRD_PARTY (BlackBox PR flow NOT adopted), Milestones M8, BUILD_BRIEF principle 5, `.env.example`.

## Tests

Updated: test_executor (manual default/capabilities/package, GitHub tests marked optional), test_executor_db, test_full_loop (golden path with no GITHUB_*; GitHub dry-run preview kept as optional), test_smoke, test_degraded_modes, test_false_success_hunt.
